# Dressmakers Line – Android Application

## Project Overview

**Dressmakers Line** is a user-friendly Android application designed to help boutique administrators efficiently manage customer details related to dressmaking, alterations, stitching, and blouse patterns. The app allows for real-time tracking of customer orders, ensuring timely delivery and smooth management of tailoring requirements.

## Technologies Used
- **Kotlin** – Main programming language for Android development.
- **Firebase Authentication** – Secure admin login functionality with role-based access.
- **Firebase Realtime Database** – Real-time database to store and update customer records.

## Features
- **Admin Authentication**: 
  - Integrated Firebase Authentication for secure login.
  - Role-based access control for boutique administrators.
  
- **Customer Management**: 
  - Manage customer details, including dress types, alterations, stitching, and blouse patterns.
  - Add, update, and delete customer records.
  
- **Real-Time Data Sync**: 
  - Firebase Realtime Database enables real-time updates to customer records, ensuring data is always synchronized across devices.
  
- **Order Tracking**: 
  - Track customer orders and their respective delivery dates.
  - Ensure timely delivery by organizing and tracking customer requests.

- **UI/UX Design**: 
  - Designed following material design principles to ensure ease of use for administrators.
  - Optimized UI for quick and efficient data entry.

- **CRUD Operations**: 
  - Implemented full **Create, Read, Update, Delete** (CRUD) functionality to allow seamless management of customer data.
  
- **Error Reduction**: 
  - Automated customer tracking processes, significantly reducing manual data entry errors by 85%.
